## 要望と解釈

要望：内容一覧の「未送信」を押して、返信記入欄へ遷移したい。

解釈：内容一覧の園返信列にある「未送信」「未送信（未入力）」「未送信の変更あり」を押せる表示にする。同じ園児・日付の詳細画面を開き、「園からの連絡」フォームへスクロールする。遷移したフォームに細い枠を付けて場所を示す。

- 日付・クラス・表示順と「内容一覧」の表示条件を引き継ぐ。一覧に戻ると表のスクロール位置も戻る。
- ボタンを押した時点では保存や公開をしない。
- お昼寝時間・体温・排便・食欲・連絡メモの全項目を現行どおり表示。既存の下書きがあればその内容を表示。
- 下書き保存、公開前の確認、変更を取り消す、未保存で移動する場合の確認は既存どおり。
- 閲覧のみの職員には記入欄へのボタンを出さず、状態を文字で表示。
- 「返信済み」と「提出状況一覧」の動作は今回の変更範囲に含めない。

合意事項：ボタンの見た目と、返信フォームの先頭へ移動する動作をモックで確認・承認済み。
