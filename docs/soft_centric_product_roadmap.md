# Nusoft / NuShift ソフト面特化型 プロダクトロードマップ（軽量コア厳選版）
## 〜単一園オールインワンで現場に即効性のある「人と保育の温かさ」を届ける〜

- **対象プロダクト**: Nusoft (`open-hoikuict`) / NuShift (`shiftai`)
- **前提条件**: **単一園オールインワン運用（`HOIKUICT_PROFILE=embedded` / 定員30名・職員20名規模）**
- **基本コンセプト**: **「管理のためのICT」から「最小の負担で人と保育の心を支えるICT」へ**
- **文書バージョン**: 3.1.0（単一園軽量コア厳選版）
- **策定日**: 2026-11-26（v3.0.0 から過剰な多園ネットワーク・監視系施策を削ぎ落とし改定）

---

## 1. 方針と見直し理由

v3.0.0 では「全国50園ネットワーク」「合同研修」「バーンアウト監視」「毎日の交換日記」など10施策を掲げていたが、単一園オールインワン（v0.8.2）の運用規模に対して開発・保守・現場入力の負担が過剰になるため、**既存機能の延長で軽く実装でき、現場に即効性がある3つのコア施策**に厳選した。

---

## 2. 厳選コア施策（3項目）

### コア1: お迎え時の「夕方30秒ハイライト」連携（旧・案6 軽量版）
- **課題**: 早番の担任が退勤した後、遅番のパート保育士がお迎えの保護者に日中の様子を伝えられず、「今日も元気でしたよ」で終わりがち。
- **軽量仕様**: 既存の連絡帳・出欠記録の「今日の一言」を、お迎え打刻時の確認画面に1行そのまま表示する（新テーブル・専用入力画面は作らない）。

### コア2: シフト「納得感」サマリ表示（旧・案1 軽量版）
- **課題**: 「土日出勤の偏り」「希望休が通ったか」の認識ズレが不公平感を生む。
- **軽量仕様**: 豪華な個別レター画面は作らず、職員のシフト閲覧画面上部に「今月の希望休充足・土日出勤回数・最大連勤数」を既存の `ShiftPlanCells` 集計から小さなバッジで表示する。

### コア3: 児童観察記録の成長タイムライン整理（旧・案4/5 軽量版）
- **課題**: 年度が変わると前年の記録を遡りづらい。
- **軽量仕様**: AIによる自動作文などは入れず、既存の児童観察記録（`child_records`）の「園児ごとの時系列一覧」の視認性・絞り込みを整える。

---

## 3. 見送り・対象外とした施策（v3.0.0 からの削除）

| 旧施策 | 見送り理由 |
| :--- | :--- |
| 案2: OJTペア1行交換日記 | 毎日30秒でも「書かなければならない入力負担」が増えるため |
| 案3: バーンアウト未然防止アラート | 勤怠・日報からのスコア判定は誤検知や監視感を生み、20名規模の園では不要なため |
| 案7: 感情共有型 温かい連絡帳 | 既存の連絡帳負担軽減と逆行する自由入力増を避けるため |
| 案8/9/10: オープン指導案マーケット・園長ピアラウンジ・50園合同研修 | 複数法人をまたぐ中央基盤・コンテンツ審査・講師手配が必要で、単一園オールインワン方針と合致しないため |
