## 1. Nusoft とは

**Nusoft** は、保育総合ICTシステム `open-hoikuict` を中核とし、職員配置基準連動型 数理最適化ソルバー **NuShift **、多要素認証 (MFA)、全銀Zenginフォーマット請求連携、および堅牢なエンタープライズ・セキュリティ基盤を完全統合した商用保育ICTプラットフォーム（個人プロジェクト商用版・全権利保持）です。

### 主な特長

1. **🧸 保育業務のワンストップ統合**
   - 園児・保護者台帳、登降園キオスク（タッチ打刻）、体温・機嫌・食事等の日次連絡帳、独自項目UUID対応の児童観察記録・指導要録、アレルギー・身体測定を含む健康管理、Web Push通知まで全業務を網羅。
2. **📱 保護者ポータル・玄関キオスクの圧倒的な利便性（最新アップデート）**
   - **👥 きょうだい一括連絡入力 & 前回コピー**: 兄弟姉妹が在籍する家庭向けに、お迎え予定・共通の生活記録・連絡事項を1画面でまとめて送信可能。直近の送信内容をワンタップで複写・自動反映。
   - **📷 スマホQRかざし打刻 ＆ 兄弟まとめ打刻**: 玄関端末のカメラにスマホのQRコードをかざすだけで、兄弟全員の登園・降園を1秒で即時打刻。朝夕の玄関「打刻渋滞」を物理的に解消。直前の誤打刻を取り消す即時Undo機能も完備。指定日打刻にも完全同期。
   - **📞 園児別・世帯別の緊急連絡先優先順位指定 (Phase 1)**: 平常時の連絡順に加え、当日の日次連絡や職員による口頭受付に基づく一時的な連絡順変更に対応。
   - **🥣 朝夕の食欲・献立入力 ＆ 閉園時刻チェック (Phase 1)**: 朝食・夕食の食欲（旺盛/普通/少なめ/ない）と献立を記録可能。閉園時刻（`closing_time`）以降の誤ったお迎え予定時刻入力を未然に防止。
   - **💴 延長保育料・請求明細のリアルタイム確認（施設別ON/OFFオプトイン対応）**: 日々の打刻から今月の暫定延長料金・分数をリアルタイム算出。確定した月次請求書および口座振替予定を兄弟別に内訳表示し、A4領収書印刷に対応。自治体一括徴収の園に配慮し、園側で機能の有効/無効をワンタップで切り替え可能（無効時は404完全ガード）。
3. **⚡ 日本初・法令配置基準連動 シフト自動作成 (NuShift Core v0.8.0 統合)**
   - 厚生労働省告示第49号（全国基準）および各自治体の独自基準（東京都、福岡市など）に完全対応。
   - **Timefold 思想に基づく独自 MILP ソルバー（PuLP/CBC / HiGHS）**: Hard/Medium/Soft 3階層スコアリング（`HardMediumSoftScore`）、局所探索多様化（LAHC）、および過剰制約計画（Overconstrained Planning）を統合。本システムはTimefold社製ソルバーを使用せず、Python標準MILPフレームワーク（PuLP経由CBC/HiGHS）で同等のスコアリング・最適化機能を提供します。
   - **過剰制約計画 & 自動診断サジェスト (v0.8.0 新機能)**: 人員不足時でも求解不能（Infeasible）に陥らず、不足コマ数（Mediumペナルティ）を最小化しながら最大限充足された安全なシフトを生成。さらに不足要因と「パート延長」「希望休出勤打診」などの自然言語サジェストを自動生成。
   - **サブセカンド即時 Re-plan (Micro Engine / v0.8.0 新機能)**: 当日朝の突発病欠に対して、MILPをスキップし局所探索（Late Acceptance Hill Climbing）を直接実行することで、確定シフト・ピン留めを完全保護しながら 0.2〜0.5 秒で代替案を即時返却。
   - **マルチテナント分離 & 不変スナップショット (v0.8.0 新機能)**: 施設ID（`facility_id`）による論理分離、楽観的排他制御（`lock_version` 409 Conflict）、および求解パラメータの不変 JSON 永続化による 100% の監査証跡を確保。
   - **分散 Solver-as-a-Service & KEDA オートスケール (v0.8.0 新機能)**: Web API 本体から重い求解ワーカーをステートレス分離。Redis キュー長に応じた 0〜20 Pods 弾力オートスケール（Spot VM 対応）により、月末ラッシュ時の Web サーバー CPU 枯渇・OOM を完全防止。
   - **制約起訴 (Indictment) & 最小破壊修復**: 各制約のペナルティ要因を追跡可視化し、突発欠勤リペア時の変更人数・コマ数を最小化。
   - **現場記号パターンモード**: 「早」「日」「遅」等の園固有勤務枠へ吸着し、現場掲示用記号マトリクスへダイレクト出力。
   - 現場の微調整を保護する「セル編集・ピン留め（Pinning）」機能、労働基準法第32条（1日10h超）違反や配置不足を自動検出して承認をブロックする「BLOCKER 承認ゲート」、急なお迎え予定変更にリアルタイム連動する「配置割れギャップ検知」を搭載。
   - 求解ジョブはDB永続キュー（`solve_jobs`）駆動型非同期ワーカーにより、サーバー再起動耐性と実行者ID記録・構造化監査ログを完備（7日間15秒以内求解の回帰防止ゲート付き）。
4. **🎥 YouTube限定公開動画ストリーミング（保護者ポータル連携）**
   - 運動会やお遊戯会の動画を、YouTube限定公開と `youtube-nocookie.com` を用いてセキュアに配信。
   - クラス別視聴制限、公開期限の自動制御、YouTube oEmbed APIによるタイトル・サムネイル自動取得、快適なページネーションに対応。
5. **💰 延長保育料自動計算 & 全銀Zengin口座振替 & 段階的締め解除 (v0.8.2 強化)**
   - 登降園実績に基づく延長料金の自動算出。
   - 全銀協標準フォーマット（Zengin）準拠の口座振替データを1クリックで生成し、金融機関とのスムーズな振替連携を実現。
   - **段階的請求締め解除 (L0/L1/L2) ＆ 園長確認フロー (v0.8.2 新機能)**:
     - **L0 (差分なし)**: 出力担当者が即座に取り消し可能。
     - **L1 (差分あり)**: 確定時と現在の打刻差分を自動事前算出し、主任等からの園長確認申請・承認を経て安全に再オープン。5つの定型理由テンプレートとインライン差分ハイライトを完備。
     - **L2 (全銀送金済み)**: 銀行送金後の二重引き落とし事故を防ぐため、管理者手動の厳格フローを維持。
   - **請求点検サマリカード & 保存セーフガード (v0.8.2 新機能)**: 月次請求の点検状況や児童別請求の誤保存を未然に防止。
   - **全銀事前チェック (Preflight) 未転送警告 (v0.8.2 新機能)**: 確定済み延長保育料が請求サイクルへ未転送のまま全銀データを作成しようとした際、事前に検知して警告案内。
   - **5MBファイルサイズ上限防御 (HTTP 413)**: 大規模データ生成時のメモリ枯渇・DoS攻撃を未然に遮断するセキュア設計。
6. **🌐 国の保育情報共有システム（PIMS）標準連携**
   - こども家庭庁・自治体標準仕様の「保育所等保育情報共有システム（PIMS）」に準拠した登降園データ連携機能を内蔵。
7. **🩺 園児健康・医療同意・午睡検温一括記録 (v0.8.2 強化)**
   - 園児ごとの血液型、かかりつけ医、希望搬送先病院、緊急時レントゲン撮影同意の保護者ポータル収集・園側承認ワークフロー。
   - **クラス午睡・定期検温一括登録 (v0.8.2 新機能)**: クラス単位や複数園児の午睡チェック（呼吸・向き良好）・検温記録をワンタップで一括登録可能。
8. **🔒 金融・医療水準のゼロトラストセキュリティ & 運用基盤**
   - メールOTPによる多要素認証 (MFA) 標準対応（TOTP専用アプリ不要、二段階セッション昇格）。
   - W3C準拠の安全な Content-Security-Policy (CSP)、Chart.js・Tailwind・HTMX ローカルバンドルによる完全オフライン＆CDN脱却。
   - CSV Formula Injection (CWE-1236) 防止ユーティリティによる安全な帳票・アンケート・児童記録エクスポート。
   - レートリミット（IP偽装防止・メモリ自動クリーンアップ機能付き）。
   - 児童・保護者・職員の機微情報アクセスおよびシフト求解要求を漏れなく追跡する監査ログ基盤。
   - Alembic による安全なスキーママイグレーションと、将来の S3/クラウド移行を見据えた `StorageDriver` 抽象化レイヤー。
   - PWA Service Worker の静的アセット事前キャッシュによるオフライン耐性と高速表示。
9. **🚀 デュアルランタイムプロファイル ＆ マルチテナント (v0.8.2 新機能)**
   - **デュアル実行モード (`profile_config`)**:
     - `ProfileMode.EMBEDDED`（デフォルト）: Redis / Docker / KEDA 不要。単一プロセス・インメモリキュー・組み込みソルバーで動作し、オンプレ・小規模園に最適。
     - `ProfileMode.CLOUD`: 分散キュー（Redis/Celery）、Serverless Solver Adapter、KEDA オートスケール、Database-per-tenant マルチテナントに対応した大規模クラウド SaaS プロファイル。
   - **NuShift 突発欠勤リペア同期 API (v0.8.2 新機能)**: 突発病欠時の修復結果（破壊コマ数最小化）をリアルタイムにシフト計画へ反映。
10. **🏛️ 保育公費加算・自治体監査対応 & ICT補助金適合**
   - **加算算定と返還リスク防止**: 3歳児配置改善加算（15:1）やチーム保育推進加算、延長保育加算などの要件を確実に満たすシフトを数理モデルで担保。自治体実地検査（指導監査）での「配置割れによる加算返還命令」を物理的に遮断。
   - **処遇改善等加算（Ⅰ・Ⅱ・Ⅲ）エビデンス**: 保有資格・職務分野別リーダー研修受講歴・年次有給休暇取得状況（年5日義務）の一元管理と勤務割実績の自動出力。
   - **保育所等ICT化推進補助金要件適合**: 登降園・連絡帳・計画記録・請求の全領域をカバーし、自治体補助金の採択基準に準拠。低コストな商用提供により、園の導入負担を抑えながら職員・園児還元を最大化。
11. **🌟 保育現場の運用摩擦解消・高負荷耐性 & UI/UX改善 (v0.8.2 強化)**
   - **児童記録自動保存 & 5領域フレーズチップ (v0.8.2 新機能)**: `hoiku-autosave.js` による自動退避、保育指針「5領域」定型文チップ、タッチ操作最適化。
   - **出欠点検ボードの安全アラート & 音響フィードバック (v0.8.2 新機能)**: 安全アラートバナー、大型タッチ操作ボタン、Web Audio API による操作確認音、クラス別クエリ最適化。
   - **職員ポータル スマート入力 (v0.8.2 新機能)**: シフト希望・有給申請でのスマート時間セレクター、理由チップ。
   - **連絡帳返信の一括承認 (v0.8.2 新機能)**: 主任・園長による未承認返信のワンタップ一括承認と公開。
   - **保護者ポータルの利便性向上 (v0.8.2 新機能)**: お迎え予定入力の補食未選択自動フォールバック、連絡帳履歴の期間指定高速化（180日上限）、管理者の保護者登録QRコード即時生成。
   - **登降園ピーク集中対策**: 参照系インメモリTTLキャッシュ（cachetools）、打刻の楽観的排他制御（HTTP 409競合防止）、htmxスケルトン＆インジケータ、Service Workerによるオフライン名簿閲覧キャッシュ。
   - **指導案の帳票力強化 & 月案一括ZIP（クラス上限20ガード）**: A4縦1ページPDF帳票、図表・園庭環境構成図添付（ReportLab自動描画）、HTML印刷プレビュー（改ページ位置リアルタイム可視化）。月案一括ZIPエクスポート（最大20クラス制限・旧形式シート互換防御）を完備。

## 4. 主要機能詳細

### 4.1 職員配置基準連動 シフト自動作成 (NuShift Core)

| 機能 | 詳細 |
| :--- | :--- |
| **基準比率設定** | 0歳児 (3:1), 1・2歳児 (6:1), 3歳児 (15:1 または 20:1), 4・5歳児 (25:1 または 30:1)。厚労省全国基準および自治体加算に対応。 |
| **数理最適化 (MILP)** | CBC ソルバーが、職員の雇用契約（常勤・非常勤）、希望休、有給休暇、連続勤務上限、休憩時間（法定45分/60分）を満たす最適シフトを週単位で算出。 |
| **手動編集 & ピン留め** | 作成されたシフト表のセルを画面上で手動変更可能。特定セルを「ピン留め」すると、再計算時にもその配置が固定保護されます。 |
| **BLOCKER 承認ゲート** | 労働基準法第32条違反（1日10時間超勤務）や法令配置割れが存在する場合、園長承認が HTTP 409 で自動遮断されます。 |
| **登降園ギャップ検知** | 保護者のお迎え予定変更や突発的な延長保育に対し、当日の必要保育士数と現行シフトの過不足（ギャップ）を即座に検知・警告。 |
| **マルチエクスポート** | 施設掲示用の「Excel 勤務割表」、給与連携用の「BOM付き CSV」、スマホカレンダー連携用の「iCalendar (.ics)」を出力。 |

### 4.2 登降園・保護者ポータル・Web Push・動画配信

- **キオスク端末打刻**: タブレットやChromebookで、園児・保護者用QR/タッチ打刻をサポート。
- **保護者ポータル & PWA**: スマホから当日の出欠連絡、お迎え時間変更、連絡帳の記入・閲覧が可能。Service Worker による主要アセットのキャッシュファースト戦略で、オフライン時や低速回線でも快適に動作。日次連絡フォームはレイヤー化（前日お世話の折りたたみ・前回コピー・統一食欲スケール「完食／ほぼ完食／半分／少なめ」・夕食リマインド通知）により保護者の入力負担を低減。
- **Web Push 通知**: ブラウザ標準のプッシュ通知技術により、アプリのインストール不要で緊急連絡や個別連絡を即時配信。
- **YouTube簡易動画配信（ムービー）**: 運動会や発表会などの動画をYouTube限定公開URLを用いて保護者へ安全に共有。
  - **oEmbed 自動取得**: 動画URLを入力し「🔍 タイトル自動取得」をクリックすると、YouTube APIキー不要でタイトルやサムネイルを即座に補完。
  - **クラス別視聴制限 & 公開期限**: 全学年共通または指定クラスのみへの視聴制御、期限到達後の自動非表示に対応。
  - **ページネーション & プライバシー保護**: 職員管理・保護者ポータル双方でページ送り表示に対応し、Cookieレス（`youtube-nocookie.com`）による高セキュアな再生環境を提供。

### 4.3 児童記録・健康管理・指導要録・医療同意

- **児童観察記録**: 日常の様子やエピソードを記録。独自項目UUIDにより、園独自の評価軸を柔軟に追加可能。
- **設定版楽観ロック**: 複数担任による同時編集時の上書き事故を完全に防止。
- **健康記録**: アレルギー情報、体温推移、定期身体測定データのグラフ表示と成長曲線の可視化（ローカルChart.jsバンドル）。
- **保護者医療同意**: かかりつけ医情報、搬送先希望、および緊急受診時のレントゲン撮影事前同意を保護者ポータルから安全に受領し、園側で確認・承認（前年度承認内容と差分ゼロの提出を自動承認する施設設定トグル対応）。

### 4.4 請求管理 & 全銀Zengin口座振替 & 締め解除

- **延長料金自動計算**: 登降園時刻の実績データから、標準時間・短時間枠、スポット・月極契約に応じた延長保育料を自動集計。
- **全銀フォーマット出力**: 全銀協規定のフォーマットに準拠した振替依頼データ（固定長テキスト）を生成し、ネットバンキングで一括引落可能。
- **締め解除（再オープン）＆ 確定前自動検算**: 確定後も管理者が安全に請求締めを解除（L0/L1/L2 段階的締め解除・園長確認フロー）し、打刻修正や再計算を実施可能。確定前自動検算では兄弟割引の自動判定と明細の不整合チェックも自動検証。

### 4.5 セキュリティ & 運用基盤

| セキュリティ機能 | 詳細 |
| :--- | :--- |
| **多要素認証 (MFA)** | メールOTP (6桁, 有効期限10分) による2段階認証。専用認証アプリ不要。 |
| **動的 CSP Nonce** | リクエスト毎に暗号学的に安全なnonceを生成し、厳格なContent-Security-Policyヘッダーを適用。XSS攻撃を遮断。 |
| **レートリミット** | ブルートフォース攻撃・DoS攻撃を防止。IP偽装対策・メモリ自動クリーンアップ付き。 |
| **監査ログ** | ログイン成功/失敗、機微情報アクセス、シフト求解要求（職員ID・パラメータ・結果）を構造化記録。 |
| **データ暗号化** | 通信はSSL/TLS暗号化。パスワードはArgon2idで不可逆ハッシュ化。 |
| **オフライン対応 (CDNフリー)** | Chart.js, Tailwind CSS, HTMX を完全ローカルバンドル化しゼロ外部依存。 |
| **ストレージ抽象化** | `StorageDriver` によりパストラバーサル防止・将来のS3移行に対応。 |
| **PWA キャッシュ** | Service Worker による静的アセット事前キャッシュでオフライン耐性・高速表示。 |

### 4.6 施設型給付費・加算算定 & 自治体監査対策

- **配置加算の法令遵守**: 3歳児配置改善加算（15:1）、チーム保育推進加算、延長保育加算など、園の取得加算に応じた配置基準をプリセット設定。
- **監査返還リスクの防止**: 自治体の実地検査（指導監査）で問題視される「配置割れ」を BLOCKER 承認ゲートで未然に防止。Excel勤務割表・登降園実績データ・監査ログを提出エビデンスとして即座に出力。
- **処遇改善等加算・キャリアパス支援**: 職員台帳での保有資格・研修修了歴・有給消化状況の管理により、処遇改善計画・実績報告の根拠データを正確に把握。
- **ICT補助金要件の網羅**: 登降園・連絡帳・要録・請求の全領域を網羅し、自治体の保育ICT化推進補助事業の要件に適合。
