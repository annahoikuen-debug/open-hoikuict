# B4: シフト過剰制約サジェスト 3ボタン 確認用モック

計画書: `docs/parent-input-reduction-phase-a-implementation-plan-2026-11-21.md`（N1 / B4 仕様）に基づく確認用モックです。
**本番DB・通知送信・ソルバー実行には一切接続しません。** すべてブラウザ内の架空データで動作します。

## 起動・確認方法

```powershell
.venv\Scripts\python.exe -m http.server 8915 --bind 127.0.0.1 --directory tools/shift-suggestion-preview
```

ブラウザで <http://127.0.0.1:8915/> を開いてください（`index.html` を直接開いても動作します）。

## 確認できる状態・操作

画面上部の確認用バー（黒帯・本番画面には出ない）で以下の状態を切り替えられます。

1. **不足あり（初期状態）**: 未承認プラン。`SHIFT_REQUEST_CONCESSION`（希望休の調整検討）と `EXTERNAL_OR_OVERTIME`（パート延長・応援要請）のサジェストに対し、「採用」「保留」「却下」の3ボタンを操作可能。
2. **解消済み（翌求解後）**: 保留していたサジェストが不足解消により自動消滅した状態、および既存の判断履歴の表示。
3. **却下済み（前回却下あり）**: 過去に同 `type` のサジェストを却下した履歴があり、新しいサジェストカードに「前回却下（理由）」バッジが自動添付される状態。
4. **打診済み（採用後）**: 希望休調整サジェストを採用して打診通知を送信済みの状態（「打診済み」表示・二重採用の409防止確認ボタン付き）。
5. **長期保留（30日超）**: 不足が解消されず30日超滞留している保留サジェストに「保留から 34 日」バッジが表示される状態。
6. **確定済みプラン（閲覧のみ）**: `plan.status == 'approved'` の場合、3ボタンが非表示となり判断不可（閲覧のみ）になる状態。
